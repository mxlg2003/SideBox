# WinDock 产品设计

## 一句话

在 Windows 11 上，按当前情境切换一组启动项、信息和轻量动作，而不接管窗口管理或 Explorer。

## 定位

WinDock 是 Dockset 一类产品的**精神续作**，对应三类能力：

1. **边缘 Dock**：应用、文件、文件夹，以及内置模块卡片。
2. **Dock 模块**：时钟、便笺、电源等嵌在 Dock 条上（Dockset 同款），按 profile 显隐，不单独开窗口。
3. **Profile 自动化**：热键、菜单、时间、显示器拓扑、Windows 11 Focus 切换“图标集合 + 桌面信息 + 声明动作”。

它不是：

- macOS 私有 API / Shortcuts / AirDrop 的等价物
- Shell 替换、任务栏替换、窗口平铺器
- 官方 Win + W Widgets 面板里的卡片（那是另一条内容分发通道，不在 MVP）

## 目标用户

- **多显示器知识工作者**：笔记本 + 外接屏切换时要换一套图标和信息。
- **Focus / 深度工作用户**：系统 Focus 开启时自动换成精简 Dock。
- **不想换 Shell 的效率用户**：要启动器与系统状态，但不替换任务栏。

## 产品原则

后续实现不得默认违反：

1. 默认不移动、不平铺、不关闭用户窗口。
2. 默认不以管理员运行；不用全局低层键盘钩子；不注入 Explorer。
3. 官方 API 为默认路径；未文档化技巧只允许实验开关，并必须自动回退。
4. 最低系统：**Windows 11 22H2 (build 22621)**。Windows 10 不是 MVP 发布门槛。
5. 权限按能力声明：媒体、网络、位置等均可撤销；崩溃上报默认关闭。
6. Profile 切换失败不得影响 Dock 的基本可用性。

## MVP 范围

**手动换情景默认关闭**（`ProductFeatures.ProfilesEnabled = false`）。出厂配置仍含 `general`（日常，不可删）和 `deep-work`（深度工作，可删），岛只用日常这一套。打开开关后可从设置「高级 → 情景」、托盘、热键切换。Focus / 显示器拓扑 / 时间规则自动切换仍关闭（`AutoProfileTriggersEnabled = false`）。

### 边缘 Dock

- 无边框、Per-Monitor v2、上 / 左 / 右边缘。设置可选显示器；把岛拖到另一块屏幕会写回 `dock.monitor`。断开屏仍迁主屏。
- **默认不占主屏底部任务栏边**。
- **默认布局：Overlay Topmost**，贴所选边缘的**居中悬浮岛**。新安装日常为时钟 + 便笺，并默认自动隐藏。内容超出时右侧出现左右箭头。不预留工作区。
- **AppBar 预留尚未产品化**（`StubAppBarService`）；可用自动隐藏避免挡最大化窗口标题栏。
- 项目类型：应用（`.lnk` / `.exe`）、文件、文件夹、内置模块（嵌在 Dock 上）。
- 左键已在运行的程序切到已有窗口（多窗口则轮换）；没有窗口才启动。右键「打开（新开一份）」始终新开。
- 从资源管理器拖入、内部拖拽排序、右键移除。重复钉选会提示「已在 Dock 上」。
- 文件夹徽标目前显示名称，不是条目数。
- 自动隐藏：空闲约 800ms 后贴边留下约 4px 细条。默认可把指针移到约 8px 热区滑出；也可关掉热区，或打开可录制的全局唤醒快捷键（默认 `Win+Shift+A`，走 `RegisterHotKey`）。全屏 / 演示避让。这三项都写当前情景的 `dock`（情景关着时就是日常）。关掉自动隐藏后岛一直置顶，热区和唤醒键保留但停用。
- 主题：浅色 / 深色跟随系统。岛面材质可选云母（更实，透明度 50%）、磨砂（雾面，0%）、玻璃（更透，80%）；之后仍可手动改底部透明度。
- 图标：按 48px 解码显示；多分辨率缓存仍是后续项。

### 内置 widget

作为 Dock 岛上的药丸卡片显示：图标加主值，不用标题行。设置的「模块」页是分类卡片目录，点预览或 + 把模块放到岛上，同一模块可添加多份；从模块右键移除。模块右键：点击有动作的才显示「打开模块」；有紧凑/展开两种内容模式的才显示这两项；均可从 Dock 移除。便笺等需要输入的模块点击后在 Dock 旁展开，不另开独立窗口。

| ID | 名称 | 数据 | 刷新 |
|---|---|---|---|
| `clock` | 时钟 | 本地时钟，可选第二时区 | 每秒或合成时钟 |
| `notes` | 便笺 | 本地 `notes\{id}.txt`，编辑时自动保存 | 变更时 |
| `sysactivity` | 系统状态 | `PerformanceCounter` CPU + 物理内存；岛上数字 / 圆环 / 条形，点开双圆环与已用内存 | 2s |
| `network` | 网络 | 适配器速率差值；岛上紧凑为速率、展开带折线，点开 60 秒图，可自定义显示项 | 1s |
| `power` | 电源 | 系统电池 + 蓝牙外设电量；岛上三种布局，点开设备列表，可自定义显示项 | 变化时 / 15s |
| `nowplaying` | 正在播放 | GSMTC 当前会话；桌面播放器未接入时回退到窗口媒体命令 | 事件 / 1s |
| `bing` | Bing 壁纸 | Bing `HPImageArchive` 近 8 日图；紧凑为圆角方形缩略图与前后/应用按钮，展开带较窄标题与日期；点应用下载 UHD 并设为桌面壁纸（Fill） | 打开时 / 1h 缓存 |
| `stopwatch` | 秒表 | 本地秒表；每份独立；点开开始 / 暂停 / 复位 | 运行中 200ms |
| `countdown` | 倒计时 | 单次倒数；命名预设；每份独立；点开设定时分秒后开始 / 暂停 / 复位，到零通知 | 运行中 200ms |
| `focustimer` | 专注计时器 | 本地番茄钟（专注/休息轮次）；每份独立；点开开始 / 暂停 / 复位与自定义 | 运行中 200ms |
| `timeprogress` | 时间进度 | 年 / 月 / 日已过比例；岛上条形 / 百分比 / 圆环，可紧凑 | 1s |

天气、本地日历为 **MVP stretch**：有时间再做，不挡发布。系统日历必须在无包身份下失败降级，禁止假装已同步 Outlook。

### Profile

一个 profile = Dock 项目集合 + widget 布局 + 外观 + 可选 L1 动作。

触发器优先级（高到低；同时满足时取最高；同级取 profiles 列表里更靠后的匹配项）：

1. 手动 / 托盘 / 热键
2. Windows 11 `FocusSessionManager`（`IsSupported == false` 时隐藏该触发器）
3. 显示器拓扑（数量、主屏、连接身份）
4. 时间段（简单日 / 周规则）

动作仅 L1：

- 切换集合与布局
- 发通知
- 默认不启动 / 退出应用
- 若用户配置了 `launch`：首次执行需确认；失败不得影响 Dock

必须提供（仅 `ProfilesEnabled` 打开时）：

- 设置「高级 → 情景」显示当前情景与切换原因
- 一键撤销（热键 `Win+Shift+Z` / 托盘 / 该页）
- 历史（原因、时间、结果；最近 100 条）
- 热键下一个情景（默认 `Win+Shift+D`）

手动切换设置 `manualOverrideUntil`：当前产品只提供「直到再次手动切换」和「本次运行结束」。自动触发未开放时，「下一次系统专注或显示器变化」不会清掉手动覆盖。

## 明确不做（MVP 与 v1 默认）

- WorkerW / Progman 桌面层、任务栏居中 / 替换、窗口平铺器
- Nearby Share / AirDrop 系统级发送
- 用注册表 / WNF 模拟 Focus Assist
- 每个 widget 一个 Electron 进程
- Microsoft Graph / To Do、Stripe / Paddle
- 官方 Widgets 面板 provider
- WebView2 社区 widget（阶段 3）
- PowerShell / Python 脚本插件（阶段 3）
- 以管理员身份常驻

## 体验要点

### Dock 层级

默认“始终可触及”：`HWND_TOPMOST` Overlay。需要在以下状态间可靠切换：正常置顶、自动隐藏、边缘滑出、全屏避让、多显示器迁移、DPI 变化重排。点击穿透只允许明确指定的背景或预览层；普通图标、拖放、右键必须可接收输入。

### 全屏避让

优先使用文档化的 `SHQueryUserNotificationState`（`QUNS_RUNNING_D3D_FULL_SCREEN` / `QUNS_PRESENTATION_MODE`），再辅以前台窗口是否盖住当前显示器。`QUNS_BUSY` 不当作全屏。禁止只靠固定间隔猜测。

### 多显示器

热插拔后，断开屏上的 Dock **必须迁移到主屏**，禁止留在无效坐标。启动和恢复时重新评估全部条件，不依赖“最后一次已知状态”单独存活。

### 隐私

首次把「正在播放」加到 Dock 时提示：将读取歌曲名、封面、播放器名称；确认后打开 `media.read`（只授给当前情景）。首次添加「网络」时提示将显示适配器名和速率，确认后打开 `networkDetails`。首次添加 Bing 壁纸时说明将访问 bing.com 并可能改写桌面壁纸。同意写入 `privacy.bingDownload`。可按 profile 关闭 `media.read`。网络 widget 不发送接口数据到云端。崩溃上报默认关。

系统专注会话（Focus）**不会**自动更换情景。模块里的「专注计时器」是本地番茄钟，不是同一件事。

## 发布形态

MVP：unpackaged Win32（x64）。不承诺 Microsoft Store。仓库提供 Inno Setup 骨架（`pack/WinDock.iss`）；有代码签名证书后再用 SignTool。开发用 `dotnet run`。
